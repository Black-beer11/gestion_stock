# Gestion de Stock

Projet de gestion de stock développé en PHP avec MySQL.

Ce projet permet de gérer les produits d’un magasin :
- ajout de produits
- modification
- suppression
- gestion des catégories
- affichage du stock

---

## Technologies utilisées

- PHP (backend)
- MySQL (base de données)
- HTML / CSS (interface)
- JavaScript (interactions)
- Git & GitHub pour le travail en équipe
